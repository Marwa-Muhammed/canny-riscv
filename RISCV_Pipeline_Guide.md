# Running the Embedded RISC-V Pipeline and Visualizing L1 vs L2 Magnitude

## Problem

The bare-metal RISC-V target has no working `fopen()` under QEMU, so the
scalar pipeline can't load an image from disk at runtime. It also can't
write output files back to disk, so there's no way to inspect results
directly.

This PR adds a self-contained embedded-image entry point that:
1. Compiles the test image into the binary as a byte array.
2. Runs the full pipeline twice on that same image — once with L1 magnitude
   (`|Gx| + |Gy|`) and once with L2 magnitude (`sqrt(Gx^2 + Gy^2)`).
3. Prints every intermediate buffer to stdout as a hex dump (since there's
   no file I/O), which gets decoded back into real `.raw` files on the host
   side and turned into comparison figures.



## Files Added / Changed

```
src/riscv_main.cpp          Embedded-image entry point (own main(), excluded
                             from the host/canny_rv builds). Loads the
                             embedded image, dumps it as "input", then runs
                             run_pipeline() twice (L1, then L2).
include/embedded_image.h    Generated header: EMBEDDED_IMAGE byte array +
                             EMBEDDED_IMAGE_WIDTH/HEIGHT/LEN. Regenerated by
                             `make embed-header`, do not edit by hand.
scripts/raw_to_header.py    Converts a .raw image into embedded_image.h.
scripts/decoder_dump.py     Parses QEMU stdout for "=== DUMP_START ... ==="
                             / "=== DUMP_END ===" blocks and writes each
                             buffer back out as build/decoded/<name>.raw.
scripts/visualize_riscv.py  Reads build/decoded/*.raw and builds two
                             combined grid figures (one per technique).
Makefile                    New targets: embed-header, canny_rv_embedded,
                             run-embedded, run-embedded-decode.
```

## L1 vs L2 Magnitude Comparison

`run_pipeline()` in `riscv_main.cpp` runs the identical 8-stage pipeline
(Gaussian → Sobel → Magnitude → Direction → NMS → Double Threshold →
Hysteresis) on the same input twice. The **only** stage that differs
between passes is magnitude:

- **L1** (`magnitude_l1`): `|Gx| + |Gy|` — cheaper, no sqrt, coarser.
- **L2** (`magnitude_l2`): `sqrt(Gx^2 + Gy^2)` — true Euclidean magnitude,
  more accurate, costs more.

Everything downstream (NMS, thresholding, hysteresis) runs on whichever
magnitude buffer that pass produced, so the divergence in the final edge
maps reflects how much the L1 approximation's error propagates through
the rest of the pipeline.

## Visualization

`visualize_riscv.py` builds **two** 2×3 grid figures:

| Panel | Source |
|---|---|
| Input Image | `input.raw` (shared, dumped once) |
| Gaussian Blur | `<prefix>_gaussian.raw` |
| Gradient Magnitude | `<prefix>_magnitude.raw` |
| NMS | `<prefix>_nms.raw` |
| Double Threshold | `<prefix>_threshold.raw` |
| Final Edges | `<prefix>_final.raw` |

Output:
- `Images/riscv_result_l1_<WIDTH>x<HEIGHT>.png`
- `Images/riscv_result_l2_<WIDTH>x<HEIGHT>.png`

**Important:** `WIDTH`/`HEIGHT` at the top of `visualize_riscv.py` are
hardcoded and must match `EMBED_W`/`EMBED_H` in the Makefile (whatever
image is currently embedded). Mismatches throw a clear `ValueError`
rather than silently misreading the buffer.

## Makefile Additions

- `EMBED_RAW` / `EMBED_W` / `EMBED_H` / `EMBED_NAME`: which image gets
  embedded and its dimensions.
- `embed-header`: regenerates `include/embedded_image.h` from `EMBED_RAW`.
- `canny_rv_embedded`: cross-compiles `riscv_main.cpp` (depends on
  `embed-header`, so the header is always current). Built from
  `EMBED_SRCS`, which excludes `main.cpp` instead of `riscv_main.cpp`.
- `run-embedded`: builds and runs under QEMU, dumps go straight to your
  terminal.
- `run-embedded-decode`: builds, runs under QEMU redirecting stdout to
  `build/qemu_output.log`, then calls `decoder_dump.py` to turn the hex
  dumps into `build/decoded/*.raw`.

## How to Run

```bash
# 1. Build, run under QEMU, and decode all hex dumps into .raw files
make run-embedded-decode

# 2. Generate the L1/L2 comparison figures
python3 scripts/visualize_riscv.py
```

Output figures land in `Images/riscv_result_l1_<W>x<H>.png` and
`Images/riscv_result_l2_<W>x<H>.png`.

To embed a different test image, set `EMBED_RAW`/`EMBED_W`/`EMBED_H` in
the Makefile (and update `WIDTH`/`HEIGHT` in `visualize_riscv.py` to
match) before running `make run-embedded-decode` again.
